MSIT Git Lab

Ein Desktop-Lernbereich für Git und GitHub: mit echten Befehlen, echten Repositories und Übungen, die du wiederholen kannst.

Lernen durch Ausprobieren

Nutze dein normales Terminal für die originalen Git-it-Challenges oder starte ein geführtes Lab. Die App prüft den Repository-Stand und speichert deinen Fortschritt auf diesem Computer.

Git Lab simuliert Git nicht. Du brauchst eine unterstützte Git-Installation auf deinem Rechner. Für Challenges mit GitHub-Konten oder Remote-Repositories brauchst du außerdem eine Internetverbindung.

Auf Git-it aufgebaut

MSIT Git Lab behält die 11 originalen Challenges bei und basiert auf Git-it von Jessica Lord und den Beiträgen der Community. Die BSD-2-Clause-Lizenz und die ursprünglichen Hinweise bleiben erhalten.

Die Desktop-App verwendet Electron. Hier findest du den Electron-Sicherheitsleitfaden.
