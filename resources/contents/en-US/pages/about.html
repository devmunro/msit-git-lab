ABOUT THE APP

MSIT Git Lab

A desktop space for learning Git and GitHub with real commands, real repositories and repeatable practice.

Learn by doing

Use your regular terminal to work through the original Git-it challenges or create a guided lab. The app checks repository state and keeps your progress on this computer.

Git Lab does not emulate Git. You need a supported system installation of Git. GitHub challenges that involve accounts or remote repositories also need an internet connection.

Built on Git-it

MSIT Git Lab keeps the original 11 challenges and is based on Git-it by Jessica Lord and its contributors. The original project’s BSD-2-Clause license and attribution are retained.

This desktop app uses Electron. Read the Electron security guide.
